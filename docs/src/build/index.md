# Build

![Assembled platform](../images/overview.png)

The platform prints on a Bambu Lab A1, or any printer with a 256 mm bed, in
about 690 g of PETG. There is nothing else to buy. It holds the Crimpdeq case
from [crimpdeq-case v2.0.0](https://github.com/crimpdeq/crimpdeq-case/tree/v2.0.0)
or any earlier release.

> [!WARNING]
> Never load the platform above its 49 kg rating, and pull only with both
> clips and the key fitted. Printed parts can fail: inspect them before each
> session and stop using any part that cracks or deforms.

## Parts

The illustrations use the same colours throughout:

- **Base** (grey), printed as a front and a rear half.
- **Anchor block** (red) and **finger grip** (blue): their lugs go into the
  two eyes of the load cell.
- **Eye clips** (yellow): hold the load cell down on the lugs.
- **Palm rest** (orange) and **index key** (green): set the hand opening.
- **Edge liner** (pink): a cap and two spacers that make the edge unlevel.
- **Pocket stoppers** (teal): make the 25 mm edge shallower.
