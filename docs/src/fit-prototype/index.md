# Fit prototype

![Assembled fit prototype](../images/overview.png)

This part of the book explains how to print and assemble the **unloaded fit
prototype** of the Crimpdeq hand dynamometer on a Bambu Lab A1, or any printer
with a 256 mm bed. It uses printed stand-ins for all hardware, so the only
thing you need to buy is glue.

> [!CAUTION]
> **Fit and comfort only. Never pull on this prototype.** The glued split frame
> and the printed bolts, pins and spacers are not load-rated. The design has
> not been load-tested, and physical fit testing is still pending.

Work through the chapters in order, starting with
[Overview and safety](overview.md).
